## 设计与选型

共同采用训练集内部的 3,804/951 整题划分，划分种子 20261015。
只用拟合部分估计标准化参数，按内部留出成绩确定参数，再在完整训练集重训。

**答案分组与训练目标**：将官方解析器得到的相同数值答案合为一组，无法解析的候选
分别成组。组特征包括候选均值、部分特征组内标准差、支持数和组数。
对比候选/答案组上的 softmax 和成对 logistic。
四个方案各从 alpha={0.001,0.01,0.1,1} 中选参，共 16 次留出搜索、四次验证。
softmax 候选目标在多个正确候选之间均分概率。一个未选中的 alpha=0.001 候选
softmax 达到 300 次迭代上限，记录为未收敛；选中的最终模型均报告收敛。

**容量和平均**：沿用成对平方损失，尝试 192/384 维投影及三个独立随机投影的
96 维模型平均。各自从 alpha={0.03,0.3,3} 中选参，共九个留出配置、三次验证。

**小型神经排序器**：从头训练 tanh 单隐层网络，加线性分支；每题内去均值，
标准化特征截断至 [-8,8]。目标为最大化选中任意正确候选的总概率。
对比隐层 32/64、权重衰减 0.001/0.01，共四种配置；Adam 学习率 0.001，
批量 128 题，最多 100 epoch，每五轮在训练留出集评估，平分取最早轮次。
选定唯一配置后，在全部训练集按所选轮数重训，只评估一次官方验证集。
最终配置为 64 隐层、衰减 0.01、30 epoch，随机种子 20261017。

## 结论与限制

本轮设置下，更复杂的模型没有胜过第二轮。不能据此推断所有分组、集成或神经模型
都无效。分组可能损失单条解答的信息，但当前实验没有单独验证这一原因。
单次训练留出集上的优势未稳定转移到官方验证集；下一步应优先通过训练集内多折
验证提高选择稳定性，并研究数学一致性特征，而非继续增加模型容量。

验证集已经跨三轮用于开发，当前最佳包含选择带来的乐观偏差。所有试验均保留，
最终测试应留到方法冻结后。不得按具体题目 ID 或参考答案写特例。

## 复现

从 code/ 运行。原始 requirements.txt 未修改；新训练依赖单列在
requirements-training.txt（SciPy 1.18.1）。所有推理只需 NumPy。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-training.txt
.\.venv\Scripts\python.exe train_round3.py --output runs/reproduced-round3
.\.venv\Scripts\python.exe train_round3_capacity.py --output runs/reproduced-round3-capacity
.\.venv\Scripts\python.exe train_round3_neural.py --output runs/reproduced-round3-neural
```

容量实验须使用新的输出目录，以免旧集合成员混入新资产。
复核当前已有资产：

```powershell
.\.venv\Scripts\python.exe verify_round3.py
```

记录位于 code/runs/round3/、code/runs/round3-capacity/、code/runs/round3-neural/。
包含搜索计划、内部留出结果/曲线、配置、权重、哈希和官方评分。
code/runs/round3/verification.json 汇总本轮接口检查与外部计时。
