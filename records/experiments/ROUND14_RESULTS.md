## 1. 先验证“未知”究竟是什么

[主计划](ROUND14_PLAN.md)直接采用上轮next-experiment：提取充分性门控与共同年龄偏移两项消融，
同时将341道未知错选按固定优先级分层。442道训练旧错的互斥类别如下：

| 类别 | 题数 |
|---|---:|
| 官方终值无法解析 | 3 |
| 题目不足3个不同数值，旧图主动排除 | 151 |
| 无受支持且数值正确的算术记录 | 91 |
| 有记录但无路径连接到官方最终值 | 56 |
| 只有1个支持节点 | 40 |
| 满足旧图已知条件 | 101 |

所以不能将未知全归因于解析器差；输入门槛、表达方式、错误算式和终值连接均可能参与。
有“图已知的正确候选”也不等于能可靠切换，必须同时统计当前正确选择的风险。
原始分层与训练索引保存在 [unknown-prerequisites.json](code/runs/round14/unknown-prerequisites.json)。

## 2. 提取充分性：降噪与失去覆盖同时发生

冻结原单位图，比较legacy、sufficiency、exact_literal三种模式，各强度0.25/0.5/1，共9条记录。
新门控要求算术等号得到检查，遇跳过的变量/单位LaTeX返回未知；更严格版本还拒绝未成等式的算式与错误等式。
明确数值错误与提取未知分开记录；未知候选不作为“完整正确替代者”的证据。

两种门控均未增加训练正确数；53个原本正确却受罚的首选减少到7个，但9个潜在纠错对象也全部消失。
留下的误罚包括连等式丢操作数、百分比补数、重复加法和未提取的口述计算。
这说明更保守可以减少噪声，却不能单凭拒绝更多输入创造纠错能力。

初版单字母变量正则把普通文字`a **40% off**`当成变量乘法；修正边界并重跑原网格后结果仍无净收益。
旧方法与第一轮产物保存于round14-gate-first-run，最终构造检查与源文件哈希另存。

## 3. 年龄偏移：复盘诊断也需要证据核对

封闭关系识别共同时间偏移下的两人年龄差，比较原图、取消安全偏移后的图与直接答案支持。
只识别到1道训练题，原模型已答对，没有可纠错的旧错。
共同偏移确实会在年龄差中抵消，但逐候选检查澄清：训练87的当前候选其实已经追踪到10，
遗漏的是`4*8+3=32+3=35`中的4。原先将其主要归因于漏掉共同偏移，诊断不完整。
角色豁免因此没有解决实际图缺陷；这项澄清保留在记录中，避免下一轮基于错误归因继续扩展。

## 4. 从具体改选案例提出并执行补充修复

训练530的`40*1.5+30*1=60+30=90`提供了另一个同类反例：原图只接受等号右侧字面数值，
忽略前一条等式，数值检查虽全部正确，最终依赖却丢了40与1.5。
先保存 [ROUND14_AMENDMENT.md](ROUND14_AMENDMENT.md)，再比较原图与精确连等式图，沿用三档强度。
修复只在两侧都是受支持、精确相等的纯数值表达式时建立依赖边，不扩大单位/代数解析，不改官方parser。
最好的固定连等式配置为4314/4755，修复1、新错0、改变23题。
新增纠错来自训练2669：原首选1152遗漏280的租金/电费；正确候选中
`1440-(288+280)=1440-568=872`被旧图截断。新图保留280的来源后，正确候选形成完整支持，选中872。
训练87中4的来源和训练530中40/1.5的来源也恢复，但这两道原本已正确，属于误罚修复。
新图改变129题的特征，受罚正确首选反而从53增加到61，说明扩展可追踪性仍可能暴露其他不完备比较。
不能用一个成功案例代替完整副作用检查；本轮仍按原资格线决定是否验证。
完整审计见 [连等式分支](code/runs/round14-chain/FINDINGS.md)。

## 6. 资源、完整性与下一轮入口

训练分支单线程；Python3.12.14、NumPy2.5.3；只用标准库和NumPy。
没有晋级方案时不运行新的推理资格基准；旧模型仍受16MiB与参考CPU完整测试30秒限制。
若进行了官方审计，完整预测与独立评分共享本地30秒，四线程；本地验证不能替代参考CPU资格。
训练文件、官方工具、历史源文件、原最佳资产和本轮冻结源码哈希通过；测试输入/标签/成绩未访问。

下一轮入口记录于 [next-experiment.json](code/runs/round14/next-experiment.json)，状态proposed_not_run。
最小新假设是修复乘法中的百分比表示一致性：20%、转义的20\%与0.20应保留相同来源。
等号右侧百分数有比例/显示歧义时仍未知，避免重犯Round8的歧义。先比较冻结连等式图与仅修此表达的新图，
固定0.25/0.5/1三档，同时记录正确首选风险。后续再区分明确连接最终值的正证据与依赖缺失；

这些是待检验假设，不能声称已经改善准确率。
