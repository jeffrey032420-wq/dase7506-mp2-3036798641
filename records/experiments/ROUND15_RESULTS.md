## 2. 百分比一致性修复解决了什么

冻结旧chain与新percent_factor两模式，各强度0.25/0.5/1，共6配置。
仅将明确乘除中的百分数转换成精确十进制原子；右侧百分数显示歧义保持未知，
不全局剥除单位或未知LaTeX。

首次实现先识别因子、后规范化\times，未触及本来要修的表达；保存首次代码/结果后，
修正既有运算符的规范化顺序，并重跑原6配置。最终28项构造检查通过。
图特征改变21题：正确首选受罚61→60；有完整正确替代者的受罚旧错9→10。
最好仍为4314（1修复/0新错），改选23→21，没有独立达到2修复门槛。
新增完整图也可能只是完整地表达了错误数量关系；重复等价等式还可能虚增支持节点数。
这些限制与全部改选审计见 [图分支FINDINGS](code/runs/round15-graph/FINDINGS.md)。

## 3. 百分比算术与最终金额义务是不同证据

明确关系分支6配置全部4313，无改选。86题/142条受支持百分比等式全部算术正确。
其中9道原错不是百分比算错：例如销售收入已算对但漏减15000债务，或保险费附着到错误成本项。
局部算对不能为完整解答背书；本轮停止扩大该族惩罚网格。

封闭债务实验仅在题目明确单项欠款与售后余额、当前终值有完整其他输入计算且未使用债务、
另一个现有官方答案为扣除债务后的值时提供支持。未知/多债务/利息等均拒绝。
具体配置、覆盖与修复/新错见 [债务选型](code/runs/round15-debt/oof-selection.json)，
典型反例与接受决定见 [债务分支FINDINGS](code/runs/round15-debt/FINDINGS.md)。
不因单例成功放宽单族至少2修复、至多1新错的预定门槛。
该债务规则实际只识别训练14，两种配置都修复1题、无新错，因此没有单独进入验证或加入累计模型。
构建图时去掉boxed外壳曾意外丢失官方终值标记；保留原官方解析值用于内部图追踪后，
重跑相同配置，初版与修复产物都保存。没有改动候选文件或官方解析器。

## 4. 累计改进必须有消融，收益需归因

旧代数惩罚和折扣规则构成without_graph控制；随后串接训练选出的固定图配置。
控制组训练4318，完整累计训练4319，本次计算图相对控制净增
1题。累计对Round11的全部收益不能都归于本轮百分比修复。
单图若未达资格，不会宣称其独立合格；累计模型按自身训练净收益筛选，并要求超过旧规则控制。
所有模型/配置先保存于frozen-selection.json，再读取验证。没有据验证继续修改规则。

| 输出 | 训练OOF /4755 | 验证 /798 | 修复 / 新错（对Round11） | 选择变化 |
|---|---:|---:|---:|---:|
| incumbent | 4313 | 748 | 0 / 0 | 0 |
| without_graph | 4318 | 748 | 0 / 0 | 0 |

累计模型的两次验证改选都发生在正确答案之间：训练后冻结的两个候选组分别仍为275和670。
